# X-PrivateMines (2026.3.0.9) - Full Buildable Source Code

Full decompiled and cleaned source code for **X-PrivateMines 2026.3.0.9** by Drawethree.

## Features & Highlights
- **100% Out-of-the-box Build**: Cleaned, un-shaded, and refactored for seamless compilation with standard Maven.
- **Companion to X-Prison**: Integrates seamlessly with X-Prison, WorldGuard, FastAsyncWorldEdit (FAWE), Vault, PlayerPoints, and ExcellentEconomy.
- **Packet-Based Private Mines Engine**: Supports PacketEvents virtual rendering.

## How to Build

### Requirements
- **Java**: JDK 17+ or JDK 21
- **Maven**: 3.8+

### Build Command
```bash
git clone https://github.com/bb99kra/X-PrivateMines-Source.git
cd X-PrivateMines-Source
mvn clean package
```

The output JAR file will be available in `target/X-PrivateMines-2026.3.0.9.jar`.
