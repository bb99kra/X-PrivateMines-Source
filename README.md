## ⚡ Core Features Breakdown

* ⚡ **Packet-Based Architecture:** Instantaneous block resets without server-side lag spikes or memory bloat, even with thousands of active mines.
* 📈 **20+ Default Upgrade Tiers:** Players can progress their private mine through customizable block compositions and progressive costs.
* 📐 **Mine Expansion System:** Expand mine dimensions dynamically to allow more mining volume as players rank up.
* 🎨 **Block Customization GUI:** Choose and select custom block types to populate the mine.
* 💰 **Tax & Monetization Economy:** Mine owners earn passive income by charging taxes on blocks mined by visitors.
* 🎟️ **Custom Entry Fees:** Charge other players an admission fee to access your personal mine.
* 🛡️ **Access Control & Ban Management:** Toggle between public/private states, ban abusive players, and manage guest access.
* ♻️ **Configurable Auto-Reset:** Triggers automated mine resets based on custom block depletion percentages (30% - 90%).
* 🔌 **Rich Integrations:** Native support for **Vault**, **X-Prison**, **PlayerPoints**, **CoinsEngine**, and **FastAsyncWorldEdit (FAWE)**.
* 💻 **Public Developer API:** Custom events for creation, reset, expansion, upgrades, bans, entry fees, and tax claims.

## 📋 Commands & Permissions

| Command | Aliases | Description | Permission |
| :--- | :--- | :--- | :--- |
| `/privatemines` | `/pmine`, `/pm` | Open main private mine GUI | `xprivatemines.use` |
| `/pmine create` | | Create a new private mine | `xprivatemines.create` |
| `/pmine teleport` | `/pmine tp` | Teleport to your private mine | `xprivatemines.teleport` |
| `/pmine reset` | | Manually reset your private mine | `xprivatemines.reset` |
| `/pmine upgrade` | | Upgrade your mine tier | `xprivatemines.upgrade` |
| `/pmine expand` | | Expand mine volume | `xprivatemines.expand` |
| `/pmine settings` | | Open private mine settings GUI | `xprivatemines.settings` |
| `/pmine ban <player>` | | Ban a player from entering your mine | `xprivatemines.ban` |
| `/pmine unban <player>` | | Unban a player from your mine | `xprivatemines.unban` |
| `/pmine kick <player>` | | Kick a player out of your mine | `xprivatemines.kick` |
| `/pmine open` | | Open mine to public visitors | `xprivatemines.open` |
| `/pmine close` | | Close mine to private mode | `xprivatemines.close` |
| `/pmine reload` | | Reload all plugin configuration files | `xprivatemines.admin` |

### 🛠️ Build Requirements & Instructions

#### 📋 System Requirements:
- **Java:** **JDK 21** *(Recommended: JDK 17 / JDK 21 LTS. Note: JDK 25+ may encounter `TypeTag :: UNKNOWN` due to upstream javac annotation processing changes)*
- **Maven:** **3.9+**

#### 💻 Build Command:
```bash
# Clone the repository
git clone https://github.com/bb99kra/X-PrivateMines-Source.git

# Enter repository directory
cd X-PrivateMines-Source

# Build with Maven
mvn clean package
```

The output JAR file will be available in `target/X-PrivateMines-2026.3.0.9.jar`.
